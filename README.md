# SKATE RUSH

3D-скейт раннер для браузера (Three.js). Пляжный город, трюки, комбо, 3 уровня.

▶ Играть: открой ссылку GitHub Pages этого репозитория в Safari на iPhone →
«Поделиться» → «На экран „Домой“» — игра установится как приложение.

Управление: джойстик ←→ смена полосы, ↑ прыжок, ↓ пригнуться; JUMP — Ollie,
FLIP — Kickflip (с ↓ Heelflip), SPIN — 360 (с ↑ Backflip), GRIND — у перил.
Клавиатура: стрелки, Пробел, J, K, L, Esc.
